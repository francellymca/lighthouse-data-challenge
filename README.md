# LH Nautical — Data & AI Challenge

Solução desenvolvida para o Desafio Lighthouse — Dados e IA.

O projeto percorre diferentes etapas de uma jornada de dados,
desde a análise exploratória e modelagem de dados até previsão
de demanda e sistemas de recomendação.

## Estrutura

- Q1 — Exploratory Data Analysis
- Q2 — Database Schema Generation
- Q3 — Data Loading
- Q4 — Customer Analysis
- Q5 — Calendar Dimension
- Q6 — Demand Forecasting
- Q7 — Recommendation System
- Dashboard — Visualização dos principais resultados

## Tecnologias

- Python 3
- PostgreSQL
- SQL
- Pandas
- NumPy
- Scikit-learn
- Power BI
